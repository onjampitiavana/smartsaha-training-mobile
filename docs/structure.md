# Structure du projet
 - pont d'entree: lib/main.dart , contient la function main() qui demarre l'application
 - Ecrans: lib/ui, la page d'acceuil actuelle est le home.dart, 
 - configuration  : 
            analysis_options.yaml: regle d'analyse du code
            android: configuration pour android
            ios: configuration pour ios
            linux: configuration specifique pour linux
            windows: configuration specifique pour windows
            MacOs: configuration specifique pour MacOs
- dependances: declarees dans pubsec.yaml
- les modèles de données: /lib/models
- Service API: lib/services
